# Assignments

Self-contained scenarios/variants built on the core subsystems (`av-sim/`, `fleet-service/`,
`ml-pipeline/`), kept separate from them so each can be assigned, graded, and iterated on
independently without touching the shared scaffolding.

- `fleet-3av-demo/` — three AV instances exercising the Fleet Management Service's full set of
  derived statuses (driving/idle/offline).
